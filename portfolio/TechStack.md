# ExpenseC — Tech Stack

## Frontend
- **Vite** — Extremely fast build tool and development server.
- **Vanilla JS / CSS** — Lightweight frontend architecture.
- **Workbox / PWA** — For Service Workers, caching, and offline capabilities.
- **Chart.js** — For visual analytics and expense breakdowns.

## Backend
- **Node.js & Express** — Lightweight server handling API routing.
- **Turso (libSQL)** — Edge-hosted SQLite database allowing seamless shared data between the Vercel serverless environment and local development.

## Infrastructure
- **Vercel** — Serverless deployment for the API and static hosting for the Vite frontend.
