# ExpenseC — Achievements & Learnings

## Key Achievements
- **Engineered a Progressive Web App (PWA):** Built a responsive, mobile-friendly application with offline capabilities via custom Service Workers and Web Push notifications, ensuring high accessibility for users on the go.
- **Optimized Settlement Algorithm:** Designed an intelligent split-expense logic engine capable of calculating optimal "explicit debts," mathematically minimizing the total number of peer-to-peer transactions required to settle group finances.
- **Deployed Edge-Hosted Infrastructure:** Architected a high-performance backend using Vercel's serverless functions seamlessly connected to a Turso (libSQL) edge database, enabling rapid API responses and simplified deployments.

## Challenges Overcome
- **Complex Financial State Management:** Ensuring accurate, real-time calculations of group expenses and settlements across multiple users required strict data normalization in the database and robust client-side state caching.
- **Progressive Enhancement:** Transitioned the application from standard web pages to a fully installable PWA, requiring meticulous handling of caching strategies and offline fallbacks.

## Possible CV Bullets
