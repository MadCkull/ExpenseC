# ExpenseC

## One-liner
A seamless Progressive Web App (PWA) for tracking shared expenses, generating settlements, and managing group finances.

## Overview
ExpenseC is a modern web application designed to simplify the process of splitting bills and calculating settlements among friends or colleagues. Architected with a single Turso (libSQL) database shared between local development and the Vercel production environment, it ensures zero data drift and instant deployments. 

## Core Features
- **Shared Expense Tracking:** Log and divide expenses among users efficiently.
- **Automated Settlements:** Calculates optimized explicit debts to minimize the number of transactions needed to settle up.
- **PWA capabilities:** Fully installable on mobile devices with offline support via Service Workers and Web Push notifications.
- **Zero-Sync Dev Environment:** Uses a unified cloud-edge Turso database so the local environment mirrors production perfectly without complex migrations.
